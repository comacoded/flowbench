Flowbench · Org transformation in five workflows

Most discovery work is already automatable. The hard part is composing it.

Flowbench is a visual workbench for designing, running, and evolving agentic workflows on top of Claude Code. Below are five real workflows pulled from MCC's iX discovery docs — each one maps to a Flowbench graph that runs end-to-end on your Claude Max subscription. None of them require an engineering ticket.

01 · Creative production

Corporate Affairs · Demand, Paid, Social

From a brief to a finished LinkedIn ad spec

Today the SM+I team takes a creative request, brainstorms with the creative strategist, drafts copy, routes to legal, gets sign-off, hands off to globalization, then delivers to the media team. Fifteen-plus handoffs across a week.

Today

5–7 days. Multiple handoffs across SM+I, Creative, Legal, PMM, Globalization, and the demand team. Brand voice and visual constraints live in scattered Sharepoint docs no one reads twice.

With Flowbench

15–20 minutes per first draft. Brand guidelines live in a Repository node and feed every step automatically. Three concept variants drafted in parallel, judged against the brief's hard constraints, and the winner is rendered directly into Figma at LinkedIn's standard ad sizes (1200×627, 1080×1080, 1080×1350).

What this exercises Repository node · Prompt with file attachment (the brief) · Multi-input fan-in (brand + brief) · Assessment with conditional branching (ship-ready / not) · Output node that drives the figma-cli skill to render the winning concept as actual Figma frames at LinkedIn's standard ad sizes.

02 · Weekly content marketing

CSR · IBM SkillsBuild

Weekly trending content report, in six languages

Every Friday a Program Manager exports an engagement CSV from SkillsBuild Service Center, ranks the top adult and high-school courses, segments by language, drafts spotlights in English and Brazilian Portuguese, then sends the lists to LEDs and Geo teams to localize for Arabic, Bahasa, French, and Spanish.

Today

Half a day, every week. Manual export. Manual ranking. Manual segmentation. Manual drafting in two languages. Manual handoff to four geo teams. Inconsistent voice across regions because no one's reading the brand doc.

With Flowbench

10 minutes. Top-5 adult and Top-5 high-school filters run in parallel. English and Brazilian Portuguese spotlights drafted in parallel. Four-language localized lists generated in parallel. All three branches converge into a single Word document the team can drop into the existing review pipeline.

What this exercises Repository node · True parallel execution at two levels · Multi-parent fan-in · Output node materializing a finished Word document so the team can keep their existing review pipeline. The clearest demonstration of Flowbench's parallel run loop in action.

03 · Monthly insights cycle

Corporate Affairs · Social Media & Influence

Monthly social media metrics & insights deck

A Social Media Intelligence Analyst downloads organic social data from Sprinklr, cleans it in Excel, curates the highlights, runs trend and YoY analysis, drafts insight callouts, and produces a monthly insights deck.

Today

Two days, every month. Most of the time goes to Excel cleaning and curation, not actual analysis. Insights are slow to surface and the deck format drifts month-to-month because every analyst structures it slightly differently.

With Flowbench

30 minutes of supervised execution. Sprinklr export drops into a Repository node, cleaning and YoY analysis run as separate Prompt nodes, and the Output node generates a real Excel workbook so the analyst can keep working in the tool they already use.

What this exercises Repository node · Sequential cleaning and analysis · Parallel YoY comparison and insight drafting · Output node materializing a real .xlsx via openpyxl so the analyst lands back in Excel.

04 · Analyst relations

Analyst Relations · RFI Response

Drafting an RFI response from an answer library

An incoming RFI lands in any of three formats. The Content Leader manually opens it, scans 50–200 questions, finds matching answers in past completed RFIs, drafts new responses where needed, and routes to the RFI owner for review. The diagram explicitly notes "introducing partial or full automation could be beneficial."

Today

1–2 weeks per RFI. The bottleneck is scanning past answers manually. Quality varies because no two analysts remember the same canonical answers.

With Flowbench

2–3 hours including human review. The Repository node points at the past-RFIs folder. The new RFI is attached to a Prompt node. Claude matches each question against the answer library, flags low-confidence questions, and only sends the uncertain ones to a human.

What this exercises Repository node (the answer library) · Prompt with attachment (the new RFI) · Assessment branching on confidence · Two parallel Output nodes — a finished Word document for the high-confidence path, a Markdown review list for the human-in-the-loop path.

05 · Strategic intelligence

CSR · Responsible Business Strategy

Peer benchmarking from a new disclosure release

When a new peer report drops, a Program Manager searches peer websites and Datamaran, document past disclosures, consolidates everything in Excel, and presents a high-level analysis in PowerPoint to executives.

Today

3–5 days per peer release. The work is mostly mechanical comparison — extract their numbers, line them up against ours, find the deltas. The actual judgment is the final 30 minutes.

With Flowbench

2 hours. Past peer disclosures live in the Repository. The new release is attached. Claude extracts scores and commitments, runs the comparison and gap analysis in parallel, then synthesizes a delta narrative for the executive deck.

What this exercises Repository node (institutional memory) · Attached new document · Parallel comparison + gap analysis · Synthesis fan-in · Output node materializing a real PowerPoint deck.

The pattern

Discovery work isn't a one-off. Make it a flow.

Every workflow above started life as a scrolling Mural diagram explaining how a team does something today. Flowbench is what you build once you've finished discovering and want the work itself to start happening on a graph instead of a Slack thread.
