# IBM Visual Tokens — Linkedin Ad Constraints

## Color (use sparingly, never more than 2 per ad)

| Token | Hex | Use |
|---|---|---|
| `--ibm-blue` | #0F62FE | Primary CTA, links |
| `--ibm-text` | #161616 | Body, headlines |
| `--ibm-bg` | #FFFFFF | Default background |
| `--ibm-bg-dark` | #161616 | Inverted background |
| `--ibm-accent-cool` | #0353E9 | Hover, supporting moments |

**Never use:** gradients on text, drop shadows, neon, more than 2 brand colors per surface.

## Type

- **Headlines:** IBM Plex Sans, weight 600, tracking -0.01em
- **Body:** IBM Plex Sans, weight 400
- **Code/data:** IBM Plex Mono
- **Minimum body size on LinkedIn:** 14px equivalent

## Layout grid (LinkedIn single image, 1200×628)

- 64px outer margin
- Logo locked to top-left, 120px wide max
- Headline takes top 40% of canvas
- CTA button bottom-right, 32px from edges
- One image, no collages

## Imagery

- Real product UI > stock photography
- People look at the camera. Not contemplating sunsets.
- One subject per frame
- No text in images. Text lives outside the image.
